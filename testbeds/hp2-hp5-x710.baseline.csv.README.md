# `hp2-hp5-x710.baseline.csv` — production baseline

Reference baseline for testbed `hp2-hp5-x710`, used by
`nix run .#flow-dissector-matrix-check` to detect cell-level
regressions in the parser performance matrix.

## Provenance

- **Promoted:** 2026-05-06 from
  `perf-results/2026-05-06/summary.csv`.
- **Sweep:** 5 reps × 4 pcaps × 2 hosts × 14 modes = 560 cell JSONs
  via `flow-dissector-matrix-run --testbed
  testbeds/hp2-hp5-x710.toml` driven from
  `/tmp/phase12-driver.sh` (one-off shell, not committed). Runner
  flake-hash was `merge/matrix-physical-testbed` HEAD =
  `3627c7c` at promotion time. Wall clock: 1083 s (≈ 18 min) end-to-end.
- **Hardware:** AMD Ryzen 5 PRO 2400G (Zen 1, 4c/8t), Intel X710
  10 GbE SFP+ (`i40e`, fw 9.30), 30 GiB DDR4-2133 on hp2 / 61 GiB
  DDR4-1866 on hp5.
- **Software:** NixOS 26.05.20260418 (`nixos-unstable` channel,
  converged on both hosts), kernel 7.0.1.
- **Tuning** (verified in `perf-results/2026-05-05/preflight.txt`):
  `mitigations=off`, `isolcpus=2-7`, `nohz_full=2-7`,
  `rcu_nocbs=2-7`, `transparent_hugepage=never`,
  `default_hugepagesz=2M hugepages=1024`, governor `performance`,
  `bpf_jit_enable=1`, `perf_event_paranoid=0`, ring 4096/4096,
  6 combined queues per NIC, GRO/GSO/TSO off, LRO `[fixed]`. See
  `docs/physical-testbed.md` §7 for the full tuning rationale.

## Schema

The CSV schema must match `CSV_COLUMNS` in
`nix/scripts/aggregate-results.py` (16 columns):

```
testbed,host,pcap,mode,n_iter,n_replicates,
ns_per_pkt_mean,ns_per_pkt_median,ns_per_pkt_p95,
ns_per_pkt_ci95_lo,ns_per_pkt_ci95_hi,
mpps_median,
build_hash,kernel,nic_driver,nic_firmware
```

Row count: **104** = 2 hosts × 4 pcaps × 13 modes. The
`c-bpf-xdp2` rows are intentionally **omitted** because the kernel
BPF verifier always rejects `flow_dissector.bpf.o` on 7.x kernels
(the documented Way 5 N/A; see `docs/flow-dissector-benchmark-plan.md`
§8). The aggregator's `parse_baseline` rejects non-numeric medians
as "incomplete baseline", so cells with no measurable data must
be filtered out before promotion.

## Regenerate

```bash
# 1. Pre-build PCAPs on both hosts (caches the derivations).
nix run .#run-on-host -- --testbed testbeds/hp2-hp5-x710.toml -- \
    test-pcap workload-pcap-https-web perf-mixed-pcap

# 2. Resolve store paths (deterministic; same on hp2 and hp5).
TEST_PCAP=$(ssh root@hp5 "cd ~/xdp2 && nix build --no-link --print-out-paths .#test-pcap")
HTTPS_PCAP=$(ssh root@hp5 "cd ~/xdp2 && nix build --no-link --print-out-paths .#workload-pcap-https-web")
MIXED_PCAP=$(ssh root@hp5 "cd ~/xdp2 && nix build --no-link --print-out-paths .#perf-mixed-pcap")

# 3. Drive 5 reps × 4 pcaps via flow-dissector-matrix-run with
#    XDP2_MATRIX_PCAP set per pcap. Pattern in /tmp/phase12-driver.sh
#    (one-off, not committed); rough shape:
RESULTS_ROOT=$PWD/perf-results/$(date -I)
mkdir -p "$RESULTS_ROOT"
for rep in 1 2 3 4 5; do
  for spec in \
    "tcp_ipv4|/root/xdp2/data/pcaps/tcp_ipv4.pcap" \
    "mixed-real|$MIXED_PCAP/mixed-real.pcap" \
    "https-web|$HTTPS_PCAP/https-web.pcap" \
    "combo|$TEST_PCAP/combo.pcap"; do
    XDP2_RESULTS_ROOT="$RESULTS_ROOT" \
    XDP2_MATRIX_PCAP="${spec#*|}" \
    XDP2_NIC_DRIVER=i40e XDP2_NIC_FIRMWARE=9.30 \
      nix run .#flow-dissector-matrix-run -- \
        --testbed testbeds/hp2-hp5-x710.toml
  done
done

# 4. Promote (filtering out null c-bpf-xdp2 rows so parse_baseline
#    accepts the file).
{
  head -1 "$RESULTS_ROOT/summary.csv"
  awk -F, 'NR>1 && $8 != "—" { print }' "$RESULTS_ROOT/summary.csv"
} > testbeds/hp2-hp5-x710.baseline.csv

# 5. Verify the regression check exits 0.
nix run .#flow-dissector-matrix-check -- --testbed testbeds/hp2-hp5-x710.toml
echo "exit: $?"

# 6. Commit:
#    feat(testbed): refresh hp2-hp5-x710 baseline ($(date -I))
```

## When to refresh

Refresh the baseline when:

- The parser implementation changes in a way that legitimately
  affects throughput (new fast path, inlining change). Don't
  refresh just to silence a regression — the gate exists to
  catch them.
- Hardware or kernel version on hp2 / hp5 changes materially (NIC
  firmware, kernel major bump, NixOS channel change).
- The benchmark methodology evolves (PCAP corpus changes, mode set
  changes — coordinate with `aggregate-results.py:CANONICAL_MODES`).

Drift detection rules (see `aggregate-results.py:write_regressions`):

- Median delta > `--threshold-pct` (default 10 %) **AND**
  CI-disjoint (new CI95-lo > baseline CI95-hi).

This dual gate suppresses small-N noise while flagging real
regressions. See `docs/flow-dissector-matrix-physical-testbed.md` §15.

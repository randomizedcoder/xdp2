# `hp2-hp5-x710.baseline.csv` — placeholder

This is the **placeholder** baseline for testbed `hp2-hp5-x710`,
used by `nix run .#flow-dissector-matrix-check`.

All `ns_per_pkt_*` columns intentionally contain `?` so the
aggregator's baseline parser rejects the file with the
documented error:

    baseline incomplete: row {...} has non-numeric ns_per_pkt_median
    or CI columns. Promote a real summary.csv before invoking
    --baseline.

This forces `flow-dissector-matrix-check` to exit non-zero
against the placeholder until a real baseline is committed.

## Regenerate (requires live `hp2`/`hp5` access)

```bash
# 1. Run the full matrix.
nix run .#flow-dissector-matrix-run -- \
    --testbed testbeds/hp2-hp5-x710.toml --results /tmp/m

# 2. Inspect the summary; sanity-check ns/pkt and Mpps.
cat /tmp/m/summary.md
cat /tmp/m/summary.csv

# 3. Promote.
cp /tmp/m/summary.csv testbeds/hp2-hp5-x710.baseline.csv

# 4. Commit:
#    perf(testbed): refresh hp2-hp5-x710 baseline (<date>)
```

The CSV schema must match the `CSV_COLUMNS` list in
`nix/scripts/aggregate-results.py`.
